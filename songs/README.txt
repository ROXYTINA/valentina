Put your music in this folder (subfolders are fine).
Supported: mp3, m4a, flac, wav, ogg, opus, aac
Name files "Artist - Song Title.mp3" so Pulse shows the right title and artist.
For lyrics, add a .lrc or .txt file with the same name, e.g. "Artist - Song Title.lrc".
Pulse picks up new files when it starts and whenever you switch back to its window.
